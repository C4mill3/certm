# Rust Cert Manager
[![crates.io](https://img.shields.io/crates/v/certm.svg)](https://crates.io/crates/certm) [![github.com/C4mill3/certm](https://img.shields.io/badge/github-repo-blue?logo=github)](https://github.com/C4mill3/certm) 

This is a tui for managing x509 certificate using openssl and ratatui


# Demo
![demo.gif](README/demo.gif)


# Info
By default, vault are stored in `"~/.certm_vault"`

# Using it

## Prerequisites
`sudo apt-get install libssl-dev pkg-config`

## Install

Simply use: `cargo install certm`

## Build And Run

To build use: `cargo build`
To run use: `cargo run -r`
